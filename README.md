# velorci — الموقع التعريفي

موقع ثابت (static) ثنائي اللغة عربي/إنجليزي، بدون أي اعتماديات وقت التشغيل:
لا React، لا CDN، لا JavaScript مطلوب لعرض المحتوى.

## البنية

```
src/
  content.js    ← كل النصوص العربية والإنجليزية — مصدر وحيد للحقيقة
  styles.css    ← نظام التصميم (CSS variables) + كل التنسيقات
  layout.js     ← قالب الصفحة: <head>، الهيدر، الفوتر
  pages.js      ← بناء الصفحات الخمس
  site.js       ← JavaScript خفيف: قائمة الموبايل، ظهور العناصر، نموذج التواصل

build.mjs       ← المولّد (Node، بدون أي حزم خارجية)
assets/         ← الصور والشعارات — تُنسخ كما هي
```

الملفات المولّدة (`index.html`, `about.html`, `en/…`, `styles.css`, `site.js`,
`sitemap.xml`, `robots.txt`, `vercel.json`) **مولّدة تلقائياً** — لا تعدّلها
يدوياً، لأن أي بناء جديد سيستبدلها. عدّل `src/` ثم أعد البناء.

## البناء

```bash
npm run build      # أو: node build.mjs
```

يولّد 15 ملف: 5 صفحات × لغتين، بالإضافة للـ CSS والـ JS وملفات SEO وإعدادات
Vercel. الملفات المولّدة محفوظة في المستودع، فالاستضافة تخدمها مباشرة بدون
خطوة بناء على السيرفر.

## تغيير الهوية البصرية

كل الألوان والخطوط والمسافات معرّفة كـ CSS variables في أعلى
`src/styles.css`. تغيير اللون الأساسي للموقع كله = سطر واحد:

```css
:root {
  --brand: #65d4d2;   /* اللون الأساسي */
  --bg: #041316;      /* الخلفية */
  --text: #e8fffe;    /* النص */
}
```

لا يوجد أي لون مكتوب يدوياً في أي مكان آخر.

## تعديل النصوص

كل النصوص في `src/content.js` على شكل `{ ar: "…", en: "…" }`. عدّل النص ثم
أعد البناء — يتحدّث في اللغتين وفي كل الصفحات التي تستخدمه.

## الروابط

| الصفحة | عربي | إنجليزي |
| --- | --- | --- |
| الرئيسية | `/` | `/en` |
| من نحن | `/about` | `/en/about` |
| الخدمات | `/services` | `/en/services` |
| فريق العمل | `/team` | `/en/team` |
| تواصل معنا | `/contact` | `/en/contact` |

الروابط النظيفة (بدون `.html`) تعمل عبر `cleanUrls` في `vercel.json`.

## ملاحظات

- **نموذج التواصل** لا يوجد له backend. عند الإرسال يفتح واتساب برسالة
  مُعبّأة مسبقاً بالبيانات. لو أردت استقبال الرسائل بالبريد أو تخزينها، يلزم
  إضافة serverless function.
- **صور المنتجات** في قسم «الأكثر مبيعاً» (`assets/prod-*.png`) هي صور
  بلاسهولدر عامة موروثة من النسخة السابقة — يُفضّل استبدالها بصور حقيقية.

## إضافة لقطة شاشة حقيقية

قسم «لوحة تحكم كاملة… في جيبك» يرسم حالياً موبايلاً وهمياً بالـ HTML.
لاستبداله بلقطة حقيقية من التطبيق:

1. ضع الصورة في `assets/` (مثلاً `assets/app-home.png`).
2. في `src/content.js` داخل `home.showcase`، غيّر:

   ```js
   screenshot: null,   →   screenshot: "assets/app-home.png",
   ```

3. `npm run build`

الموبايل الوهمي يختفي تلقائياً وتحلّ الصورة محلّه. اتركها `null` ما دامت
لا توجد لقطة حقيقية — رسمٌ يتظاهر بأنه لقطة شاشة يكلّف ثقةً أكثر مما يكسب.

## نبرة المحتوى

النصوص مكتوبة لجمهور محدّد: **تجّار انستقرام وواتساب الذين يوصّلون
بأنفسهم**. القاعدة عند أي تعديل: تحدّث عن وضع التاجر، لا عن بنية المنتج.
«طلباتك بتوصلك على الخاص» أقوى من «منصة تشغيل أعمال متكاملة».

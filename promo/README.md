# إعلان velorci — نسخة 54 ثانية بتعليق صوتي خليجي + نسخة 30 ثانية سريعة (9:16)

إعلان عمودي 1080×1920 بـ 30fps لـ Reels وTikTok وSnapchat. الصوت مضبوط على ‎-14 LUFS‏ (معيار منصات التواصل)، والذروة ‎-1.5 dBTP.
الشاشات لقطات حقيقية من تطبيق velorci بشكل الموبايل داخل إطار جوال (متجر LAYA التجريبي) — التفاصيل في قسم «الواجهات».

**التعليق الصوتي** مولّد بصوت Microsoft العصبي الكويتي `ar-KW-FahedNeural`، وكل عبارة تبدأ مع ظهور ميزتها (التوقيتات بالجدول أدناه).
تحقّقت منه بتفريغه آلياً إلى نص، فطابق السيناريو. للحملات المدفوعة، الأضمن توليد نفس الصوت عبر اشتراك Azure Speech
(نفس اسم الصوت)، لأن شروط الاستخدام التجاري لخدمة القراءة في Edge غير واضحة. أو سجّل بصوت معلّق على نفس الجدول ثم:
`./build.sh --skip-render --vo voice.wav`.

## إعادة البناء

```bash
cd promo
./build.sh                               # 54 ث مع التعليق الصوتي -> deliverables/velorci-ad.mp4 (+ _no-vo)
./build.sh --skip-render --vo voice.wav  # تعليق صوتي مسجّل بملف واحد يبدأ من 0 ث
./build.sh --skip-render --vo-lines vo/  # ملف لكل عبارة: vo/intro.wav و vo/f1.wav … vo/f13.wav و vo/logo.wav
./build.sh --cut 30                      # النسخة السريعة 30 ث
```

المتطلبات: Node مع Playwright (Chromium)، ffmpeg، وpython3 مع numpy وscipy، وedge-tts للتعليق الآلي (يحتاج إنترنت).
للمعاينة الحية افتح `promo/index.html` في المتصفح — المسافة: تشغيل/إيقاف، الأسهم: إطار بإطار، R: من البداية (تُعرض نسخة الـ30 ث افتراضياً؛ التوقيت الكامل يُحقن عند التصوير).

| الملف | الدور |
|---|---|
| `index.html` | كل المشاهد على خط زمني واحد (GSAP) |
| `render.mjs` | تصوير 900 إطار وتمريرها إلى ffmpeg |
| `audio/build_audio.py` | توليد الموسيقى والمؤثرات والتعليق الصوتي وخلطها |
| `timing.json` / `timing-30s.json` | توقيت كل نسخة (مدة الميزة، الإيقاع، الصوت) |
| `mux.py` | دمج الصورة والصوت وضبط الصوت على ‎-14 LUFS |

## الحقوق

- الموسيقى والمؤثرات مولّدة برمجياً في `audio/build_audio.py` — بلا عينات ولا تراخيص طرف ثالث.
- خط Cairo: ‏SIL Open Font License (`vendor/OFL-Cairo.txt`). ‏GSAP 3.12.5: رخصة GreenSock القياسية.
- التعليق الصوتي: صوت Microsoft العصبي `ar-KW-FahedNeural` (انظر ملاحظة الترخيص أعلاه).
- أسماء وشعارات بوابات الدفع والمنصات معروضة نصاً للإشارة إلى تكاملات موجودة فعلاً.

# إعلان velorci — ‏30 ثانية (9:16)

إعلان عمودي 1080×1920، مدته **30.000 ثانية بالضبط** (900 إطار، 30fps)، جاهز لـ Reels وTikTok وSnapchat.
الصوت مضبوط على ‎-14 LUFS‏ (معيار منصات التواصل)، والذروة ‎-1.5 dBTP.

**التعليق الصوتي الخليجي الاحترافي لم يُسجَّل هنا** — يحتاج معلّق صوتي (أو خدمة صوت مرخّصة تجارياً مثل Azure Speech بصوت `ar-KW-FahedNeural`).

## الواجهات: إعادة رسم من الواجهة الحقيقية، لا لقطات شاشة

لوحة التحكم تحتاج تسجيل دخول، فلم تُلتقط منها صور. كل شاشة في الإعلان أُعيد رسمها بألوان الهوية وخط Cairo والتسميات الحرفية من كود اللوحة.
**لاستبدالها بلقطات حقيقية:** ضع الصورة في `screens/` باسم الميزة، وأعد البناء (`./build.sh`). تحل الصورة محل محتوى نافذة تلك الميزة تلقائياً.

## إعادة البناء

```bash
cd promo
./build.sh                       # صورة + موسيقى  -> deliverables/velorci-ad-30s.mp4
./build.sh --skip-render --vo voice.wav   # إضافة تعليق صوتي مسجّل (30 ث، يبدأ من 0)
```

المتطلبات: Node مع Playwright (Chromium)، ffmpeg، وpython3 مع numpy وscipy.
للمعاينة الحية افتح `promo/index.html` عبر خادم محلي (مثلاً `python3 -m http.server` من جذر المستودع) — المسافة: تشغيل/إيقاف، الأسهم: إطار بإطار، R: من البداية.

| الملف | الدور |
|---|---|
| `index.html` | كل المشاهد على خط زمني واحد (GSAP) |
| `render.mjs` | تصوير 900 إطار وتمريرها إلى ffmpeg |
| `audio/build_audio.py` | توليد الموسيقى والمؤثرات وخلط التعليق الصوتي |
| `mux.py` | دمج الصورة والصوت وضبط الصوت على ‎-14 LUFS |

## الحقوق

- الموسيقى والمؤثرات مولّدة برمجياً في `audio/build_audio.py` — بلا عينات ولا تراخيص طرف ثالث.
- خط Cairo: ‏SIL Open Font License (`vendor/OFL-Cairo.txt`). ‏GSAP 3.12.5: رخصة GreenSock القياسية.
- صوت Piper المؤقت (`ar_JO-kareem`) ترخيص بياناته غير واضح للاستخدام التجاري — لهذا هو للتوقيت فقط.
- أسماء وشعارات بوابات الدفع والمنصات معروضة نصاً للإشارة إلى تكاملات موجودة فعلاً.
